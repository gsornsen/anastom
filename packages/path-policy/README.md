# @anastom/path-policy

Provide distinct capabilities for authored local paths and Anastom-owned private state. `canonicalExistingRoot(root)` and `resolveExistingChild(root, input, expectedType)` confine an existing child to a caller-authorized canonical directory while permitting an internal symlink target. `ensurePrivatePathRoot(path)` creates or validates a current-user-owned private root and exposes fixed-segment directory creation, bounded descriptor reads, atomic record replacement, immutable exclusive publication, and bounded socket-path construction. `PrivatePathError` classifies changed, invalid, oversized, wrongly owned, and wrongly typed private-state paths without weakening fail-closed handling.

This operation is used for Fake scenario file references and the control-plane verifier's working directory. The CLI also applies it to operator-selected Task/Workflow files and their schema references under its current directory, so a path from CLI arguments cannot make the loader read outside that explicit local source scope. Run Anastom from a directory containing the authored source tree; `--repo` may still select a separate target Git repository. Direct core loaders remain local APIs for trusted callers that authorize their own files.

The authored-child operation is deliberately unsuitable for private state. The private-root capability accepts only fixed filename components, rejects symlinked run-owned parents, uses modes `0700` and `0600`, and verifies file identity around bounded reads. Replacement serves mutable operational records. Exclusive publication atomically creates immutable manifests and artifacts, accepts an identical existing record idempotently, and rejects different bytes. The capability assumes the current local account is trusted. End-user authentication stores, signed executable provenance, managed-policy discovery, and model-private native file-tool inputs retain their own semantics. [ADR 0016](../../docs/adr/0016-path-policy-after-third-adapter.md) records the third-adapter comparison. The [durable execution production contract](../../docs/M3_PRODUCTION_CONTRACT.md) defines the private-state boundary. The [public source entry](src/index.ts) has JSDoc; generate optional API HTML with `pnpm docs:api path-policy`.
