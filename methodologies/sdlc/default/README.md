# Default defined SDLC

This checked-in methodology turns one strict Feature contract into analysis, a bounded task plan, isolated implementation, deterministic integration, two independent reviews, and operator-authored verification. Anastom snapshots every prompt and output schema before execution; a resumed run never reloads changed package files.

The planner emits data only. Trusted control-plane code validates task bounds, dependencies, repository-relative mutation scopes, and disjoint dependency waves before it expands the durable graph. Verification commands come only from the Feature document.

All six roles use the run's selected runtime and model. Role-specific runtime routing remains future work. Analyst, planner, and reviewers are read-only. Implementer and integrator roles receive isolated mutation policy.
