# Support

Use GitHub Discussions for setup questions, workflow design, ideas, and community help. Use GitHub Issues for reproducible bugs and accepted implementation proposals.

Before asking for help, search the documentation, existing discussions, and issues. Include the Anastom revision, operating system, Node.js and pnpm versions, the command you ran, the smallest safe reproduction, and the complete error output.

Community support is best-effort and has no response-time commitment. Commercial use is welcome, but the issue tracker is not a substitute for a vendor's own integration, regression testing, or customer-support staff. Reports that improve Anastom for the wider community are prioritized over organization-specific operational requests. Independent paid support providers may participate if they identify their affiliation and do not imply project endorsement.

Never include credentials, private source code, personal data, or proprietary model transcripts. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
