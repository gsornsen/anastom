## Identities and environment

The owner accepted the design and [ADR 0015](adr/0015-claude-code-worker-profile.md) in [PR #20](https://github.com/gsornsen/anastom/pull/20), merged as `1ffaffc4ab84b39d3a2916a74bd1bd38d9bcd437`. The M2.5 implementation branch is `feat/m25-claude-code-worker`; its signed-off commit and implementation PR identities will be recorded after submission. [ADR 0016](adr/0016-path-policy-after-third-adapter.md) is a proposed path-policy follow-up decision for owner review, not a shipped API.

The local audit ran on 2026-09-15 with Node.js `26.4.0`, pnpm `11.9.0`, macOS Darwin `25.2.0` on arm64, and the end-user-installed native Claude Code `2.1.268`. The separately verified Anthropic signed-release manifest's `darwin-arm64` SHA-256, `06a96d5423f83770f120859f1c58e60d7252cc4c122aa13043b7e7cd716bc76a`, matched the operator's native-installer file. The published GPG signing-key fingerprint was `31DDDE24DDFAB679F42D7BD2BAA929FF1A7ECACE`; detached-manifest verification reported a good signature. The adapter fixes the manifest hashes for supported Darwin/Linux arm64/x64 variants, rehashes the separately installed ordinary executable before each attempt, and never looks up a release binary on PATH. The proprietary executable is neither a project dependency nor an AGPL redistribution. The exact source/package audit is in [M2.5 feasibility](M2_5_FEASIBILITY.md).

The selected live profile is Anthropic `claude-opus-4-8` with the end user's `subscription` source. The owner separately authenticated the unmodified Claude Code CLI using its normal Claude.ai login. The adapter's model-free preflight admitted only the allowlisted status form `loggedIn:true`, `authMethod:claude.ai`, `apiProvider:firstParty`, `subscriptionType:max`; it discarded account identity and organization data. A script run outside the filesystem sandbox printed only `subscription-source-confirmed`, `absent-by-conservative-gate`, both filesystem workspace modes, native structured output, and `modelCalls:0`. The API-key mode requires the operator's own ambient key, invokes official `--bare`, never falls back to Claude.ai login, and has no live API-billed call in this evidence.
